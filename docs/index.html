Bookmarks are not the problem.

Forgetting they exist is.

A useful project gets mentioned in a YouTube description. A friend sends a long-form article. You save it. You never see it again.

1

Rediscovery feed

The new tab is a weighted-random pick from your saved bookmarks. Recent items boosted. Repeatedly shown items down-weighted. Items you mark done get zero weight.

2

Bookmark manager

Every saved link in one tab. Inline icons per card: edit tags, move to a Chrome folder, delete, star. Tag edits attempt to move the bookmark into the matching Chrome folder.

3

Reading list and Done

A distinct one-time-read pile. Items captured via Attic auto-join. A star toggles membership. Mark done sends to Done. Undo done returns.

Five ways to save

Use whichever surface fits the moment. Everything lands in the same local store.

A

Toolbar popup

Segmented control picks Reading list or Bookmarks, then save.

⌘

Keyboard shortcut

Cmd/Ctrl + Shift + S anywhere in Chrome.

▸

Right-click menu

Save page or Save link from the context menu.

⇆

Chrome bookmarks sync

Your existing Chrome bookmarks appear automatically. No manual import.

↥

Pocket import

Drop in your ril_export.html and Attic walks it into IndexedDB.

!

Ask-mode notifications

Capture defaults to "Ask each time" so every save lets you pick Reading list or Bookmarks via a Chrome notification.

Local-first by design.

Every saved URL, every piece of metadata, every image lives in your browser's IndexedDB. The only outbound network requests are metadata fetches to the exact URLs you saved.
